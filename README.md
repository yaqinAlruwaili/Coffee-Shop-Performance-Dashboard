# ☕ Coffee Shop Performance Dashboard | Sales & Profitability Analysis

## 1. Project Overview

This project focuses on analyzing coffee shop sales data and developing an interactive **Coffee Shop Performance Dashboard using Microsoft Power BI** to provide insights into sales performance, profitability, customer ordering patterns, and product category performance.

The dashboard transforms raw transaction data into meaningful visualizations and key performance indicators (KPIs), helping identify sales trends, understand order patterns, and evaluate business performance across different cities and branches.

The project uses two main tables:

- **Fact_Coffee:** Contains the coffee shop's transactional data.
- **Dim_Date:** Provides date-related attributes for time-based analysis.

## 2. Project Objectives

Develop an interactive dashboard to:

- Monitor overall sales, revenue, and profitability performance.
- Analyze monthly revenue and profit trends.
- Understand order patterns across different days and months.
- Compare revenue performance across cities and product categories.

## 4. Data Preparation & Transformation

The data preparation process included the following steps:

- **Dataset Understanding:** Reviewed and examined the source data to understand its structure and contents.
- **Data Type Correction:** Checked and corrected column data types to ensure data consistency and accurate analysis.
- **Date Table Creation:** Created a dedicated `Dim_Date` table using DAX to support time-based analysis and reporting.
- **Data Modeling:** Established a One-to-Many (1:*) relationship between `Dim_Date` and `Fact_Coffee` using the date column, with **single-direction cross-filtering** from `Dim_Date` to `Fact_Coffee` to enable accurate time-based filtering and analysis.

## 6. Key Insights & Observations

The analysis revealed several important business insights:

- **Overall Performance:** Generated approximately **$46K in revenue** and **$16K in profit** from **9,971 orders** and **14K units sold**.
- **City Performance:** Chicago contributed the highest revenue share at **24%**, followed by Los Angeles at **23%** and New York at **22%**.
- **Product Categories:** Desserts recorded the highest revenue among product categories, followed by Sandwiches and Tea Beverages.
- **Monthly Demand:** May recorded the highest number of orders at **909**, while February recorded the lowest at **744**.
- **Daily Order Patterns:** Friday recorded the highest order volume among the days of the week, at approximately **1.5K orders**.
